# 🌤️ Weather Website

A modern and responsive Weather Website built using **HTML**, **CSS**, and **JavaScript**. It provides real-time weather information for any city using the **OpenWeatherMap API**.

![Weather Website Banner](https://via.placeholder.com/1000x300?text=Weather+Website)

## 🚀 Live Demo

🔗 **Website:** https://your-live-demo-link.vercel.app/

> Replace the above link with your deployed website URL (GitHub Pages, Netlify, or Vercel).

---

## 📌 Features

- 🔍 Search weather by city name
- 🌡️ Real-time temperature
- 💧 Humidity information
- 🌬️ Wind speed display
- 🌤️ Dynamic weather icons
- ❌ Error handling for invalid city names
- 📱 Fully responsive design
- 🎨 Modern UI with gradient card design

## 🛠️ Built With

- HTML5

- OpenWeatherMap API

## 🔑 API

This project uses the **OpenWeatherMap API**.

Get your free API key here:

https://openweathermap.org/api

Replace your API key inside the JavaScript file.

```javascript
const apiKey = "YOUR_API_KEY";
```

## 📖 How It Works

1. Enter a city name.
2. Click the search button.
3. The application sends a request to the OpenWeatherMap API.
4. Weather details are displayed instantly.
